# Appetizers Homebrew tap

Install [Outrider](https://github.com/appetizers-io/outrider), a CLI that watches
GitHub PR activity and opens local Claude Code or Codex sessions.

```sh
brew tap appetizers-io/tap
brew install --cask appetizers-io/tap/outrider
/opt/homebrew/bin/outrider --version # Apple Silicon; use your brew prefix elsewhere
```

Homebrew may ask you to trust the cask when installing from a third-party tap.
The cask depends on `gh` and `git`. Install Claude Code or Codex separately;
`tmux` is needed only for the tmux launcher. Then run `gh auth login`,
`outrider doctor`, and `outrider config generate --write`.

```sh
brew upgrade --cask appetizers-io/tap/outrider
```

The cask includes macOS arm64 and amd64 release archives. Linux users can use
[release archives](https://github.com/appetizers-io/outrider/releases) if their
Homebrew version does not support casks on Linux. The binaries are not signed
or notarized; the macOS install hook removes the quarantine attribute.

The cask is generated by Outrider's GoReleaser workflow. Make changes to
[its source configuration](https://github.com/appetizers-io/outrider/blob/main/.goreleaser.yaml),
not directly to `Casks/outrider.rb`.

See the [setup guide](https://github.com/appetizers-io/outrider/blob/main/docs/getting-started.md)
and [configuration reference](https://github.com/appetizers-io/outrider/blob/main/docs/configuration.md).
